# Vyravo AI — Discovery Call Automation

Standalone discovery call booking & AI lead qualification system for [vyravo.ai](https://vyravo-ai.vercel.app).

- AI-powered lead qualification with real-time scoring
- Personalized service recommendations
- Booking flow that saves leads to the shared CRM database (Neon Postgres)
- Webhook endpoint for Calendly/Stripe integrations

Part of the Vyravo AI app family:
- Main site: https://vyravo-ai.vercel.app
- Email Automation: https://vyravo-ai-email-automation-yf54.vercel.app
- CRM: https://vyravo-ai-crm.vercel.app

## Development
```bash
npm install
npm run dev
```
